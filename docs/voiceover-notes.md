# Voiceover notes

The script to paste into your text-to-speech tool is
[`voiceover.txt`](voiceover.txt) — that file contains nothing but the spoken
words, so you can paste the whole thing without trimming anything out.

132 words, which lands between **53 and 61 seconds** depending on the voice.

## If the acronyms come out wrong

Most modern voices read these correctly. Only substitute one after you have
actually heard it get it wrong:

| In the script | Replace with |
| --- | --- |
| `XLM` | `X L M` |
| `USDC` | `U S D C` |
| `DEX` | `decks` — it is said as a word, not spelled out |
| `IPFS` | `I P F S` |
| `NFTs` | `N F Ts` |
| `CI` | `C I` |
| `README` | `read me` |
| `Soroban` | `SORE-oh-ban` |

## Pacing

The five paragraphs are the five shots in
[`video-script.md`](video-script.md). Generate them as one file if your tool
preserves the paragraph pauses; otherwise generate each paragraph separately
and line them up with the matching shot — which also lets you redo a single
line without regenerating the whole thing.

| Paragraph | Shot |
| --- | --- |
| 1 | Landing view, swap page |
| 2 | Type 25, quote fills, click Swap, five stages tick through |
| 3 | Point at the new row in Registry events, `fee … (30bps)` |
| 4 | `/mint`, drop image, CID appears, mint into the pool |
| 5 | Resize to phone width, cut to the green Actions tab |
